git init [ initiliases Repository ]
git status [ Track changes and current status ]
git add [ adds files and foldes for staging / stages them ]
git restore --staged [ unstages all staged changes ]
git restore [ restores all uncommited changes back to original commit ]
git add . [ stages all in current directory ]
git add --all [ stages all in project folder ]
git add * [ stages new/modified files not deleted ]
git commit -m "message" [ adds staged changes to local Repository ]
git rm [ removes and stages a file/folder ]
git reset [ removes staged changes ]
git reset --hard [ returns all changes back to inital commit ]
git log [ log of commits ]
git branch [ shows list of all branches ]
git branch BranchName [ create new branch ]
git checkout BranchName [ move to another branch ]
git merge BranchName -m "message"
git checkout CommitID [ rollback to previous commit ]
git diff [ shows the different changes ]
git dff id1 id2 [ shows difference between two commits ]
git push Remote Branch [ pushes changes to remote repository ]
git pull Remote Branch [ pull chages from remote repository and merges ]
git fetch Remote Branch [ fetches changes from remote repository and does not merge ]
git stash [ saves uncommited changes ]
git stash list [ as name suggests ]
git stash drop [ removes stash ]
git stash pop [ applies stashed elemtns, remove from stash list ]
git stash apply [ applies and keeps stash in stash list ]
git revert [ undo the changes made by a previous commit by creating a new commit ]
git rebase [ allows continues merging from a branch ]
